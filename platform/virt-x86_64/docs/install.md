# Running virt-x86_64

There is nothing to install. This board is a VM, so "install" means "boot the
image you built" — which is the honest version of what every other board's page
describes, minus the risk.

## Before you start

Nothing is destroyed. The image is a file under `out/images/virt-x86_64/`, and
the worst outcome is a VM that does not boot.

You need a built image:

```sh
make image BOARD=virt-x86_64
```

See [docs/BUILDING.md](../../../docs/BUILDING.md) for what comes before that.

## Console

The console is your terminal. QEMU runs with `-nographic` and the kernel is
given `console=ttyS0`, so everything arrives on stdout — the same serial console
a real board offers, with no cable.

## Booting it

```sh
make vm BOARD=virt-x86_64
```

Leave QEMU with **Ctrl-a x**.

## First boot

Boot takes a few seconds. In order, the console shows the kernel, then
`NOSAIC-INITRAMFS starting`, the image being mounted and the overlay assembled,
`NOSAIC-BOOT userspace reached`, s6 bringing up the supervision tree, and a
login prompt.

Log in as **`admin`**. There is no password — NOSaic ships without one, so no
image is ever reachable with a credential its author already knows. Set one with
`passwd`; it lands on the data partition and survives upgrades and rollbacks.

Shut down with `poweroff`.

## Choosing a slot

```sh
make vm BOARD=virt-x86_64 SLOT=b
```

Slot A is the default. Slot B is empty until something is installed into it —
see `make image-ab`, which exercises an upgrade and a rollback end to end.

## When it does not work

**QEMU exits at once, "vmlinuz missing".** No image built yet. `make image
BOARD=virt-x86_64`.

**Kernel panics, no init.** The initramfs did not find the slot. `console.log`
from the automated boot (`make image-boot`) is kept beside the image and shows
how far it got.

**A login prompt but no supervision tree.** s6 failed to bring a service up. The
service definitions are generated by `svcgen` from the recipes' abstract
`services:` stanzas — the failure is in the definition, not in a hand-written
unit file, because there are none.
